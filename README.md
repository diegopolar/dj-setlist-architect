# DJ Setlist Architect
Flutter (Android). Offline-first (SQLite).
## Compilar
1. flutter create --platforms=android --project-name dj_setlist_architect .   (dentro de esta carpeta; no pisa lib/ ni pubspec.yaml)
2. flutter pub get
3. flutter run                      # prueba en dispositivo/emulador
4. flutter build apk --release      # build/app/outputs/flutter-apk/app-release.apk
